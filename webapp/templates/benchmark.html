How it is graded

Fault lines
The buggy program's code lines that the fix deletes or rewrites. Comments, blank lines and re-indentation are ignored. When a fix only adds code (an omission), the code lines on either side of the insertion stand in.
Warned
The selected rules report anything at all on the buggy program.
Hit
One of those warnings is on a fault line.
Detected
A hit whose rule fires less often on the fixed program: the fix is what silenced it.
Warnings on fixed programs
The fix resolved the bug, so most warnings still left there are false alarms.
On a fault line
The share of the warnings on buggy programs that land on a fault line, a rough precision.
Comparing another tool
Run it over benchmarks/bugs4q/programs/, then python benchmarks/run_bugs4q.py --import-sarif results.sarif --tool mytool. Its results then appear in the comparison table of every run.
